Why is this an issue?

An OrderError is reported when a cryptographic operation is not fully completed as expected (IncompleteOperationError) or executed in the wrong order (TypestateError). CrySL rules define a specific order of operations (e.g., an encryption process requires initialization before performing encryption, followed by finalization). If a required step is missing or in the wrong place, the cryptographic process may remain incomplete, potentially leading to unencrypted data, insecure partial outputs, or unexpected runtime failures. This error ensures that cryptographic workflows are executed in their entirety and in their intended sequence to maintain security.

How to fix it

The following operations must be executed in the correct order:

  1. getInstance
    • Cipher.getInstance(String transformation)
    • Cipher.getInstance(String transformation, String provider)
    • Cipher.getInstance(String transformation, Provider provider)
  2. init [at least once]
    • c.init(int opmode, Certificate certificate)
    • c.init(int opmode, Certificate certificate, SecureRandom random)
    • c.init(int opmode, Key key)
    • c.init(int opmode, Key key, SecureRandom random)
    • c.init(int opmode, Key key, AlgorithmParameters params)
    • c.init(int opmode, Key key, AlgorithmParameters params, SecureRandom random)
    • c.init(int opmode, Key key, AlgorithmParameterSpec paramSpec)
    • c.init(int opmode, Key key, AlgorithmParameterSpec paramSpec, SecureRandom random)
  3. updateAAD [optional, can be called more than once]
    • c.updateAAD(byte[] aadBytes)
    • c.updateAAD(byte[] aadBytes, int aadOffset, int aadLen)
    • c.updateAAD(ByteBuffer aadByteBuffer)
  4. Continue with either option 1 or 2 [XOR]:
    1. wrap [can be called more than once]
      • byte[] wrappedKeyBytes = c.wrap(Key wrappedKey)
    2. Update and finalize [can be called more than once]
      1. update [optional, can be called more than once]
        • byte[] preCipherText = c.update(byte[] prePlainText)
        • byte[] preCipherText = c.update(byte[] prePlainText, int prePlainTextOffset, int prePlainTextLen)
        • c.update(byte[] prePlainText, int prePlainTextOffset, int prePlainTextLen, byte[] preCipherText)
        • c.update(byte[] prePlainText, int prePlainTextOffset, int prePlainTextLen, byte[] preCipherText, int preCipherTextOffset)
        • c.update(ByteBuffer prePlainTextByteBuffer, ByteBuffer preCipherTextByteBuffer)
      2. doFinal
        • byte[] cipherText = c.doFinal() [only after having previously called update]
        • byte[] cipherText = c.doFinal(byte[] plainText)
        • c.doFinal(byte[] cipherText, int cipherTextOffset) [only after having previously called update]
        • byte[] cipherText = c.doFinal(byte[] plainText, int plainTextOffset, int plainTextLen)
        • c.doFinal(byte[] plainText, int plainTextOffset, int plainTextLen, byte[] cipherText)
        • c.doFinal(byte[] plainText, int plainTextOffset, int plainTextLen, byte[] cipherText, int cipherTextOffset)
        • c.doFinal(ByteBuffer plainTextByteBuffer, ByteBuffer cipherTextByteBuffer)
