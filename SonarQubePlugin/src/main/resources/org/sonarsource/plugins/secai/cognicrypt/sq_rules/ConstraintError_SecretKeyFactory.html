Why is this an issue?

A ConstraintError is triggered when a cryptographic API is used with parameters that do not comply with security constraints defined in the CrySL rule. These constraints can apply to algorithm selection, key sizes, padding schemes, or cryptographic modes. Such an error indicates that the provided argument violates predefined security policies, which could result in weak encryption, predictable cryptographic outputs, or even insecure configurations that attackers can exploit.

How to fix it

A new SecretKeyFactory is created not through a constructor but by calling one of the following:

SecretKeyFactory.getInstance(String algorithm);
SecretKeyFactory.getInstance(String algorithm, Provider provider);
SecretKeyFactory.getInstance(String algorithm, String provider);

The algorithm must be one of:

  • PBKDF2WithHmacSHA512
  • PBKDF2WithHmacSHA384
  • PBKDF2WithHmacSHA256
  • PBKDF2WithHmacSHA224
  • PBEWithHmacSHA512AndAES_128
  • PBEWithHmacSHA384AndAES_128
  • PBEWithHmacSHA384AndAES_128
  • PBEWithHmacSHA224AndAES_128
  • PBEWithHmacSHA256AndAES_128
  • PBEWithHmacSHA224AndAES_256
  • PBEWithHmacSHA256AndAES_256
  • PBEWithHmacSHA384AndAES_256
  • PBEWithHmacSHA512AndAES_256
