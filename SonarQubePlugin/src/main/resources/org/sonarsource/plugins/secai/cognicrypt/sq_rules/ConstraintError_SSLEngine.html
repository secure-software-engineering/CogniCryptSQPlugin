Why is this an issue?

A ConstraintError is triggered when a cryptographic API is used with parameters that do not comply with security constraints defined in the CrySL rule. These constraints can apply to algorithm selection, key sizes, padding schemes, or cryptographic modes. Such an error indicates that the provided argument violates predefined security policies, which could result in weak encryption, predictable cryptographic outputs, or even insecure configurations that attackers can exploit.

How to fix it

For the following two methods of SSLEngine multiple contraints have to be fulfilled:

sslEngine.setEnabledCipherSuites(String[] cipherSuites);
sslEngine,setEnabledProtocols(String[] protocols);

The elements of protocols must be one of:

  • TLSv1.2
  • TLSv1.3
If protocols contains TLSv1.2, then all elements of ciphersuites must be among the following:
  • TLS_ECDHE_ECDSA_WITH_AES_128_GCM_SHA256
  • TLS_ECDHE_ECDSA_WITH_AES_256_GCM_SHA384
  • TLS_ECDHE_RSA_WITH_AES_128_GCM_SHA256
  • TLS_ECDHE_RSA_WITH_AES_256_GCM_SHA384
  • TLS_DHE_DSS_WITH_AES_128_GCM_SHA256
  • TLS_DHE_DSS_WITH_AES_256_GCM_SHA384
  • TLS_DHE_RSA_WITH_AES_128_GCM_SHA256
  • TLS_DHE_RSA_WITH_AES_256_GCM_SHA384
  • TLS_ECDH_ECDSA_WITH_AES_128_GCM_SHA256
  • TLS_ECDH_ECDSA_WITH_AES_256_GCM_SHA384
  • TLS_ECDH_RSA_WITH_AES_128_GCM_SHA256
  • TLS_ECDH_RSA_WITH_AES_256_GCM_SHA384
If protocols contains TLSv1.3, then all elements of ciphersuites must be among the following:
  • TLS_AES_128_GCM_SHA256
  • TLS_AES_256_GCM_SHA384
