Why is this an issue?

An OrderError is reported when a cryptographic operation is not fully completed as expected (IncompleteOperationError) or executed in the wrong order (TypestateError). CrySL rules define a specific order of operations (e.g., an encryption process requires initialization before performing encryption, followed by finalization). If a required step is missing or in the wrong place, the cryptographic process may remain incomplete, potentially leading to unencrypted data, insecure partial outputs, or unexpected runtime failures. This error ensures that cryptographic workflows are executed in their entirety and in their intended sequence to maintain security.

How to fix it

The following operations must be executed in the correct order:

  1. getInstance
    • Signature.getInstance(String algorithm)
    • Signature.getInstance(String algorithm, String provider)
    • Signature.getInstance(String algorithm, Provider provider)
  2. Either sign or verify:
    • Sign:
      1. initSign [can be called more than once]
        • sig.initSign(PrivateKey privateKey)
        • sig.initSign(PrivateKey privateKey, SecureRandom random)
      2. Update and sign: [can be called more than once]
        1. update [can be called more than once]
        2. sig.update(byte inputByte)
        3. sig.update(byte[] input)
        4. sig.update(byte[] input, int offset, int len)
        5. sig.update(ByteBuffer inputByteBuffer)
        6. sign [can be called more than once]
        7. byte[] output = sig.sign()
        8. sig.sign(byte[] output, int offset, int len)
    • Verify:
      1. initVerify [can be called more than once]
        • sig.initVerify(Certificate cert)
        • sig.initVerify(PublicKey, publicKey)
      2. Update and verify: [can be called more than once]
        1. update [optional, can be called more than once]
        2. sig.update(byte inputByte)
        3. sig.update(byte[] input)
        4. sig.update(byte[] input, int offset, int len)
        5. sig.update(ByteBuffer inputByteBuffer)
        6. verify [can be called more than once]
        7. boolean verified = sig.verify(byte[] sign)
        8. boolean verified = sig.verify(byte[] sign, int offset, int len)
