Why is this an issue?

A ConstraintError is triggered when a cryptographic API is used with parameters that do not comply with security constraints defined in the CrySL rule. These constraints can apply to algorithm selection, key sizes, padding schemes, or cryptographic modes. Such an error indicates that the provided argument violates predefined security policies, which could result in weak encryption, predictable cryptographic outputs, or even insecure configurations that attackers can exploit.

How to fix it

A ConstraintError has occurred due to the use of invalid parameter values with KeyPairGenerator.

This error typically happens when the key size does not match the required value for the selected algorithm, or when an unsupported algorithm is used.

To solve the issue, following constraints must be satisfied:

  • algorithm must be one of: {"RSA", "EC", "DSA", "DiffieHellman", "DH"}
  • If algorithm == "RSA", then keysize must be 3072 or 4096
  • If algorithm == "DSA", then keysize must be 3072
  • If algorithm == "DiffieHellman" or "DH", then keysize must be 3072
  • If algorithm == "EC", then keysize must be 256

To resolve this issue, update the algorithm and keysize values so they match the required combinations defined by the CRYSL rule.

Correct Usage Example (RSA):

import java.security.KeyPairGenerator;

public class KeyGenExample {
 public void generateRSAKeyPair() throws Exception {
  KeyPairGenerator keyGen = KeyPairGenerator.getInstance("RSA");
 keyGen.initialize(4096);  // Valid key size
 keyGen.generateKeyPair();
}
}

Avoid:
  • Using unsupported algorithms like MD5 or Blowfish
  • Using RSA with 2048 or smaller keys
  • Using EC with keysize != 256

Complying with these constraints ensures that the generated key pairs meet modern cryptographic security requirements.
