Why is this an issue?

A ConstraintError is triggered when a cryptographic API is used with parameters that do not comply with security constraints defined in the CrySL rule. These constraints can apply to algorithm selection, key sizes, padding schemes, or cryptographic modes. Such an error indicates that the provided argument violates predefined security policies, which could result in weak encryption, predictable cryptographic outputs, or even insecure configurations that attackers can exploit.

How to fix it

A new KeyAgreement is created not through a constructor but by calling one of the following:

KeyAgreement.getInstance(String algorithm);
KeyAgreement.getInstance(String algorithm, Provider provider);
KeyAgreement.getInstance(String algorithm, String provider);

Here, the algorithm given must be one of:

  • DH
  • DiffieHellman
  • ECDH


Also, the following call should never be made:

SecretKey sharedKey = keAgreement.generateSecret(symmetricKeyAlgorithm);
Instead use 
byte[] sharedSecretBuffer = keyAgreement.generateSecret();
or
