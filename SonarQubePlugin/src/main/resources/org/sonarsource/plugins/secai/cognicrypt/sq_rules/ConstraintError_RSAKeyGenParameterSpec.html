Why is this an issue?

A ConstraintError is triggered when a cryptographic API is used with parameters that do not comply with security constraints defined in the CrySL rule. These constraints can apply to algorithm selection, key sizes, padding schemes, or cryptographic modes. Such an error indicates that the provided argument violates predefined security policies, which could result in weak encryption, predictable cryptographic outputs, or even insecure configurations that attackers can exploit.

How to fix it

The RSAKeyGenParameterSpec is being used with insecure parameters. the key size here must be either 3072 or 4096 bits, and the public exponent must be 65537.

To resolve this issue, you must initialize RSAKeyGenParameterSpec with values that comply with the CRYSL rule.

Compliant Configuration:

  • Key size: 3072 or 4096
  • Public exponent: 65537

Example Fix:
import java.security.spec.RSAKeyGenParameterSpec;
import java.math.BigInteger;

public class SecureRSAConfig {
 public void setup() throws Exception {
 int keySize = 4096;
 BigInteger publicExponent = BigInteger.valueOf(65537);
 RSAKeyGenParameterSpec spec = new RSAKeyGenParameterSpec(keySize, publicExponent);
 // Use this spec with your KeyPairGenerator
}
}

Avoid: Using smaller key sizes like 2048 or public exponents like 3.

This ensures compliance with modern security recommendations and prevents cryptographic vulnerabilities.
